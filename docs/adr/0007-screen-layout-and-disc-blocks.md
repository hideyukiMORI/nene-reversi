# ADR 0007 — 画面の文字は ASCII だけ、石は升とは別の色で塗った偶数桁の空白、盤は 2 段の大きさ

- 状態: 受理（決定 2 の石の形と決定 3 の `[ ]` を書く行は ADR 0009 で置換）
- 日付: 2026-10-26
- Issue: #5
- 影響する規則: ARC-011 / SWF-014 / FR-07 / FR-10 / FR-15 / FR-16

## 文脈

施主の決定（REQUIREMENTS）: 石は文字ではなく升とは別の色で塗った偶数桁のブロック（Q4・FR-07）、直前の手は打った石の升を `[ ]` で囲む（Q5）、
HUD に石の数（Q6）、端末の大きさで 2 段の配置（FR-16）。

兄弟の NeNe Gambit では、端末の「幅の答え」と「描かれる幅」が違う文字（駒記号）で位置と色を直すのに 4 往復かかった（Gambit ADR 0008・0010・0011・0013）。
Unicode の Emoji の性質を持つ文字は前景色が効かず、East Asian Ambiguous の文字は端末によって幅が変わる。
SWF-014 は「罫線・HUD・セリフの文字が何桁を占めるかの前提は Render の 1 か所で決め、ADR に書く」とした。

## 決定

1. **画面に書く文字はすべて ASCII**（1 文字 1 桁の前提が崩れない）。文言は `Wording` の 1 か所だけが持ち、英語の大文字で書く。
   罫線の枠（FR-16 の後半）と 12 テーマは手順 5 で、実機の画面写真で幅を確かめてから足す
2. **石のセルは空白で、背景色だけを石の色にする**。升は市松の 2 色で塗り、石はその上に別の色で塗る。
   大きな盤は 1 升 6 桁 × 3 行で、石は 2・4・2 桁の 3 行（端末のセルは縦長なので丸く見える）。縮小版は 1 升 4 桁 × 2 行で、石は 2 桁 × 2 行
3. 直前の手の升は、大きな盤では真ん中の行、縮小版では両方の行の左右の端に `[` と `]` を強調の色で書く（石の塗りと重ならない）。直前の手がパスなら何も囲まない
4. 配置は「上端に題とシード・左に盤（行の番号は左、列の文字は下）・右に HUD・下端にキーのヘルプ」。必要な大きさは配置から計算し、
   大きな盤は 91 × 29、縮小版は 69 × 21。どちらも入らなければ `TERMINAL TOO SMALL: NEED 69x21` の 1 行だけを書く
5. HUD（FR-10 のうち手順 2 の分）: 局の番号・手番（終局なら `OVER`）・手数・石の数・通算の勝敗と引き分け・終局の結果と次の局までの秒読み・直近の手（入るだけ）。
   手の表記（`d3`・`PASS`）は `MoveNotation` の 1 か所だけ。1 行目は盤の上端
6. 色は `Theme` の 1 か所だけが持つ。いまは 1 テーマで、NeNe Gambit の既定テーマ NEON の配色を写し、駒の 2 色を石の 2 色に当てた

## 強制

- **active**（テスト・`make check` の `test` 段）:
  - 石の色で塗ったセルはすべて空白で、その数は石の数 × 1 個の石のセルの数に一致する（大きな盤・縮小版の両方）
  - 画面のすべての文字が ASCII
  - 文字のあるセルは前景と背景のコントラストが 4.5:1 以上、石の色は 2 色の升に対して 3:1 以上（WCAG の文字・文字でない図形の基準）
  - 直前の手の升だけが `[ ]` で囲まれる・小さすぎる端末では 1 行だけで盤を描かない・0 × 0 でも落ちない
- **planned**: Windows Terminal での実際の見え方（色・石の形・速さ）は機械では見られない。Phase 3 の手順 3 で実機の画面写真を撮って確かめる

## 結果

- Gambit が踏んだ字形の幅と絵文字の罠（Gambit ADR 0008・0010・0011・0013）は、石では起きない。画面の文字が ASCII だけなので、HUD でも起きない
- 失うもの: 罫線の枠と記号による演出は、手順 5 で幅を測る仕組み（Gambit ADR 0007 のカーソル位置の問い合わせ）を移植するまで使えない
- 正直に記録しておくこと: NEON の「黒」の駒の色（ピンク）をそのまま黒石に当てたので、黒石がピンクに見える。HUD は `BLACK` と書く。
  テーマが石の色を決めるのは FR-07 のとおりだが、黒石らしく見えるかは手順 3 の画面写真で施主に見てもらう

## 却下した選択肢

| 選択肢 | 却下の理由 |
| --- | --- |
| `●` / `○`（U+25CF / U+25CB）で石を描く | East Asian Ambiguous で、端末によって 2 桁で描かれる（Gambit の駒記号と同じ罠）。施主の決定（Q4）とも違う |
| `⚫` / `⚪`（U+26AB / U+26AA） | Emoji の性質を持ち、前景色が効かない（Gambit ADR 0013） |
| 石を升いっぱいに塗る | 升と石の境目が見えにくく、盤の目が消える。市松の升の中に一回り小さく塗るほうが石に見える |
| 盤の目を罫線で描く | 罫線の幅は端末によって違い、測る仕組みがまだ無い（手順 5） |
| 縮小版を 1 升 2 桁 × 1 行にする | 石と升の色の区別が 1 セルの中ではつかず、`[ ]` を置く場所も無い |
